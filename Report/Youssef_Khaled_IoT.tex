\begin{abstract}
This paper presents the work completed during the IoT Summer Research Internship 2026 at the Nanoelectronics Integrated Systems Center (NISC), Nile University. The internship focused on embedded systems, Internet of Things (IoT), and real-time operating systems through a series of hands-on tasks. The developed solutions demonstrated communication between embedded devices and cloud services while providing practical experience in embedded software development, cloud technologies, wireless communication, and system integration.
\end{abstract}

\section{Introduction}

The Nile University Summer Research Internship 2026 provided an opportunity to gain practical experience in embedded systems, Internet of Things (IoT), and real-time software development through a series of hands-on engineering tasks. The internship emphasized applying theoretical knowledge to real-world embedded applications while introducing modern software and communication technologies widely used in industry.

Throughout the internship, three major technical areas were explored. The first focused on Embedded Linux development using the Raspberry Pi, where Python was employed to interface with hardware peripherals and implement different GPIO control techniques. The second addressed the design of an end-to-end IoT system by transmitting sensor measurements from edge devices to cloud services using both HTTP and MQTT communication protocols. The collected data were stored in a time-series database and visualized through a real-time monitoring dashboard. Finally, the internship introduced real-time embedded software development using TI-RTOS on the Texas Instruments CC1352P1 LaunchPad, where multiple concurrent tasks including LED control, Bluetooth communication, Zigbee communication, and UART-based communication with the Raspberry Pi were implemented.

In addition to software implementation, the internship emphasized understanding the design trade-offs between different communication protocols and software architectures. The progression from basic hardware interfacing to cloud connectivity and finally to multitasking embedded systems provided a comprehensive view of modern IoT system development.

This report summarizes the assigned tasks, describes the methodologies followed during implementation, presents the achieved results, and discusses the technical knowledge and practical skills acquired throughout the internship.

\subsection{Raspberry Pi Development}

\subsubsection{Objective}

The objective of this task was to develop a solid foundation in software development on Embedded Linux while learning the fundamentals of hardware interfacing using the Raspberry Pi. \subsubsection{Task 2.1 -- C Programming Fundamentals}

The first stage focused on strengthening programming skills using the C language within the Raspberry Pi Linux environment. The implemented application solved the Emirp Number problem, where prime numbers whose digit-reversed values are also prime were identified within a user-defined range.

The program was developed using a modular design by separating the functionality into helper functions responsible for primality testing and digit reversal. Dynamic memory allocation was employed to store the resulting Emirp pairs, while structures were used to organize the associated data, including the prime number, its inverse, and the numerical difference between them. Input validation was also incorporated to detect invalid ranges and incorrect user entries before executing the algorithm.

This task provided practical experience with:

\begin{itemize}
    \item Programming in C under Embedded Linux.
    \item Modular software development using functions.
    \item Structure-based data organization.
    \item Dynamic memory allocation using \texttt{malloc()}.
    \item Input validation and error handling.
    \item Compilation and execution using the GNU Compiler Collection (GCC).
\end{itemize}

\subsubsection{Task 2.2 -- Embedded Linux and GPIO Programming}

The second stage introduced hardware interfacing using the Raspberry Pi GPIO pins. Python was used to control LEDs and read the state of a push button through the GPIO interface provided by the Linux operating system.

Three different software approaches were implemented for LED control:

\begin{itemize}
    \item \textbf{Delay-based control}, where software delay loops generated the blinking period.
    \item \textbf{Timer-based control}, where timing mechanisms were used to improve execution accuracy.
    \item \textbf{Interrupt-based control}, where GPIO interrupts enabled immediate response to button presses without continuous polling.
\end{itemize}

These implementations demonstrated how different software architectures influence processor utilization, timing accuracy, and system responsiveness while using identical hardware.

\subsection{Internet of Things (IoT)}

\subsubsection{Objective}

The objective of this task was to develop a complete Internet of Things (IoT) data acquisition system capable of collecting sensor measurements, transmitting them to cloud platforms, storing them in a time-series database, and visualizing the acquired data in real time. Throughout the internship, two communication approaches were investigated. The initial implementation utilized HTTP requests with the Adafruit IO platform, while the final system adopted the MQTT publish/subscribe protocol together with InfluxDB and Grafana to improve communication efficiency and enable scalable real-time monitoring.

\subsubsection{Work Performed}

The implemented IoT system consisted of multiple software components working together to provide end-to-end data acquisition and visualization. Sensor measurements were collected by the Raspberry Pi using Python, after which the measured values were transmitted to cloud services. During the first implementation, the Raspberry Pi periodically uploaded sensor readings to Adafruit IO using the HTTP protocol. Although functional, this approach required continuous polling and repeated request generation.

The second implementation migrated the communication layer to MQTT. The Raspberry Pi published sensor measurements to an MQTT broker whenever new data became available. The broker forwarded the received messages to InfluxDB for permanent storage, while Grafana retrieved the stored measurements directly from the database to generate live dashboards and historical plots.

\subsubsection{Database Integration}

To enable persistent storage and historical analysis of sensor measurements, the received MQTT messages were stored in an InfluxDB time-series database. Unlike conventional relational databases, InfluxDB is specifically designed for timestamped data, making it well suited for Internet of Things (IoT) applications where measurements are continuously generated over time. Each sensor reading was recorded together with its corresponding timestamp, allowing efficient querying, filtering, and long-term storage of collected data. This database served as the primary data source for the Grafana visualization platform, enabling both live monitoring and analysis of previously recorded measurements.

\subsubsection{Methodology}

Two communication protocols were implemented and evaluated throughout the internship.

The first implementation employed the HTTP protocol, where the Raspberry Pi continuously transmitted sensor measurements to the cloud using periodic HTTP requests. Since the client must repeatedly request communication regardless of whether new data are available, this approach increases network traffic, processor activity, and power consumption.

The second implementation adopted the MQTT publish/subscribe communication model. Instead of continuously polling the server, the Raspberry Pi publishes sensor values only when new measurements become available. Subscribers automatically receive updates from the MQTT broker whenever new messages are published. Consequently, MQTT significantly reduces unnecessary network traffic while providing lower latency and improved scalability for IoT applications.

\subsection{Real-Time Operating System (RTOS)}

\subsubsection{Objective}

The objective of this task was to gain practical experience in real-time embedded software development by implementing concurrent applications using a Real-Time Operating System (RTOS). The work focused on understanding task management, scheduling mechanisms, inter-task execution, and communication between embedded devices while developing a multitasking application on a wireless microcontroller platform.

\subsubsection{Work Performed}

The RTOS application was organized around a central kernel responsible for scheduling multiple independent tasks. Each task executed concurrently while sharing the processor according to the scheduling policy provided by the operating system. This architecture allowed different application functionalities to execute independently without blocking one another.

The implemented software consisted of several concurrent tasks responsible for hardware control, wireless communication, and external device interaction. Synchronization between these tasks was managed by the RTOS scheduler, ensuring deterministic execution and efficient processor utilization.

Figure~\ref{fig:rtos_architecture} illustrates the overall RTOS architecture implemented during the internship.

\begin{figure}[H]

    \caption{RTOS architecture showing the kernel managing multiple concurrent tasks.\cite{repo}}
    \label{fig:rtos_architecture}
\end{figure}

\subsubsection{Implemented Modules}

Four independent application tasks were developed during this stage:

\begin{itemize}
    \item \textbf{LED Task}: Periodically controlled the onboard LED to demonstrate periodic task scheduling.
    
    \item \textbf{Bluetooth Task}: Implemented Bluetooth communication for wireless data exchange.

    \item \textbf{Zigbee Task}: Established Zigbee communication for low-power wireless networking.

    \item \textbf{UART-over-USB Task}: Enabled serial communication between the RTOS device and the Raspberry Pi for system integration.
\end{itemize}

Each task executed independently under the supervision of the RTOS kernel, demonstrating concurrent execution without interfering with the operation of other tasks.

\subsubsection{Outcomes}

The RTOS implementation successfully demonstrated multitasking capabilities through the concurrent execution of independent application tasks. The scheduler efficiently managed processor time among the implemented tasks while maintaining responsive system behavior.

Successful Bluetooth and Zigbee communication verified the operation of multiple wireless interfaces under the RTOS environment. In addition, UART-over-USB communication established reliable integration between the RTOS microcontroller and the Raspberry Pi, allowing both platforms to exchange data as part of a unified embedded system.

\section{Summary of Work Accomplished \& Outcomes}

The IoT Summer Research Internship provided a progressive learning experience that combined embedded Linux, Internet of Things (IoT), and real-time embedded systems into a unified practical project. Beginning with software development on the Raspberry Pi, the internship gradually expanded toward cloud-based IoT communication and concluded with the implementation of real-time applications using an RTOS-enabled wireless microcontroller.

The work began with developing software applications under the Embedded Linux environment using the Raspberry Pi. Fundamental programming concepts were reinforced through C programming exercises, followed by Python-based GPIO interfacing to control LEDs and read push-button inputs using different software approaches, including delay-based, timer-based, and interrupt-driven techniques.

Building upon this foundation, the developed embedded applications were connected to cloud services to form a complete IoT monitoring platform. Sensor measurements were transmitted using both HTTP and MQTT communication protocols, allowing their performance to be evaluated and compared. The collected data were then stored in an InfluxDB time-series database and visualized through Grafana dashboards, enabling live monitoring and historical data analysis.

The final stage focused on real-time embedded software development using an RTOS. Multiple concurrent tasks were implemented, including LED control, Bluetooth communication, Zigbee communication, and UART-over-USB communication with the Raspberry Pi. The RTOS scheduler successfully coordinated these independent tasks, demonstrating reliable multitasking and efficient processor utilization.

Overall, the internship resulted in a complete end-to-end embedded IoT system capable of acquiring sensor measurements, transmitting them through lightweight communication protocols, storing them within a scalable database, visualizing them in real time, and integrating embedded Linux with an RTOS-based microcontroller platform. \section{Conclusion and Future Work}

\subsection{Conclusion}

The IoT Summer Research Internship at the Nanoelectronics Integrated Systems Center (NISC), Nile University, successfully achieved its intended learning objectives by providing comprehensive practical experience in embedded systems, Internet of Things (IoT), and real-time software development.

Throughout the internship, progressively connected tasks were completed, beginning with Embedded Linux programming and Raspberry Pi hardware interfacing, followed by the development of a complete IoT monitoring system using cloud communication technologies, and concluding with Real-Time Operating System (RTOS) application development on an embedded microcontroller. These activities provided practical experience in software development, wireless communication, cloud services, database management, and system integration.

Beyond the technical implementation, the internship strengthened problem-solving abilities, research methodology, technical documentation, teamwork, and presentation skills. The combination of theoretical concepts and hands-on experimentation provided valuable insight into the complete lifecycle of designing, implementing, testing, and integrating embedded IoT systems.

Overall, the internship established a strong foundation for future work in embedded systems, IoT, and real-time applications while providing practical engineering experience applicable to both academic research and industrial projects.

\subsection{Future Work}

Although the developed system successfully demonstrated end-to-end IoT communication and embedded software development, several enhancements can further improve its functionality and scalability. Future work may include:

\begin{itemize}
    \item Integrating additional environmental and industrial sensors.
    \item Expanding the IoT platform to support a larger number of connected devices.
    \item Enhancing MQTT communication using authentication, encryption, and secure communication mechanisms.
    \item Deploying the developed applications on industrial-grade embedded hardware.
    \item Extending the RTOS application with additional concurrent tasks, synchronization mechanisms, and advanced scheduling techniques.
    \item Incorporating edge artificial intelligence (Edge AI) and local analytics to reduce cloud dependency and enable intelligent decision-making at the device level.
\end{itemize}
