# NU-IoT-Research-Intern

This repository contains the complete documentation, source code, reports, presentations, and implementations developed during the **Nile University Summer Research Internship 2026**.

## Project Overview

During this internship, several Internet of Things (IoT) concepts were implemented using Raspberry Pi, embedded systems, cloud platforms, and real-time operating systems.

The repository includes:

- Raspberry Pi development using Embedded Linux and Python
- Hardware interfacing with sensors and GPIO
- IoT cloud communication using HTTP and MQTT
- Real-time data storage and visualization
- FreeRTOS task scheduling and multitasking
- Bluetooth and Zigbee communication
- Integration between Raspberry Pi and RTOS-based embedded systems
- Final presentation and report
